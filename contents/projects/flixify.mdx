> ## Short Explanation

Flixify is a comprehensive movie and TV series discovery platform that provides users with an intuitive way to explore entertainment content. The application features advanced search capabilities, personalized bookmarking, user authentication, and a customizable viewing experience with theme switching functionality.

> ## Project Goals

Flixify was developed to address several key user needs in entertainment discovery:

- Create an intuitive platform for discovering movies and TV series
- Provide personalized user experience through bookmarking and authentication
- Implement advanced search functionality across all content
- Offer customizable viewing experience with theme options
- Build a scalable, performant application using modern web technologies
- Demonstrate full-stack development capabilities with database integration

The project leverages a robust, modern tech stack:

- **Next.js**: Full-stack React framework providing server-side rendering and API routes
- **TypeScript**: Type-safe development for better code quality and maintainability
- **Prisma**: Modern database toolkit for type-safe database access and management

> ## Features

### Content Discovery
Comprehensive movie and TV series exploration with detailed information and ratings.

### Advanced Search
Powerful search functionality that works across all pages and content types.

### User Authentication
Secure user registration and login system for personalized experiences.

### Bookmark System
Personal bookmark collection to save favorite movies and TV series for later viewing.

### Theme Switching
Customizable dark/light theme options for comfortable viewing in any environment.

### Responsive Design
Fully responsive interface optimized for desktop, tablet, and mobile devices.

### Type Safety
Built with TypeScript for enhanced code reliability and developer experience.

### Database Integration
Prisma ORM provides efficient, type-safe database operations and management.
