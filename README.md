# Personal Portfolio Website

My name is Dev Harsh Agarwal, and I'm a Full Stack Engineer. I enjoy turning ideas into smooth, functional, and creative digital experiences — with a strong foundation across the modern web and cloud stack (TypeScript, React, Next.js, Node.js, and AWS), and a deep curiosity about artificial intelligence.

I built this website to showcase my work, experiment with new technologies, and stay up to date with the latest trends in the tech world.

## Tech Stack

**Client:** React, Next.js, TypeScript, TailwindCSS, Framer Motion, GSAP.

**AI Chat:** LangChain + LangGraph, OpenRouter (Mistral), Tavily web search.

**Backend:** Next.js Route Handlers, Nodemailer.

**Hosting:** Vercel.

## Run Locally

Clone the project

```bash
  git clone https://github.com/Devharsh01/<repo>
```

Go to the project directory

```bash
  cd <repo>
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run dev
```
